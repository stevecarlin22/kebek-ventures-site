# Kebek Ventures Website (Next.js)

This is a modern, professional rebuild for kebekventures.com.

## Deploy without coding
1. Create a GitHub repo and upload the contents of this folder.
2. In Vercel, click New Project → Import the repo → Deploy.
3. In Vercel, add your GoDaddy domain and follow the DNS instructions.

## Notes
- Contact form uses a mailto link by default (no backend required).
- You can wire a form provider later (Formspree, Basin, etc.).
